# AI内容创作系统 v1.0

## 项目目标

每天自动生成AI前沿资讯情报包和爆款公众号文章。

## 系统架构

```
数据采集层 → 分析处理层 → 内容创作层
  (6源)      (打分+深度)    (选题+成稿)
```

## 执行时间

每天09:10-09:55（45分钟）

## 技术方案

- Twitter: Nitter镜像（免费）
- 融资数据: 爬虫+交叉验证
- 公众号: 自动化浏览器控制（微信读书号）
- GitHub: 对比shkyyy18所有项目（除mi_fitness_data_bridge）
- 风格学习: 花叔+卡兹克+新智元（全学）

## 当前状态

## 目录结构

```
intelligence/     # 情报层
  collectors/     # 采集脚本
  analyzers/      # 深度分析
  daily/          # 每日产出

  styles/         # 风格库
  generators/     # 生成器
  drafts/         # 草稿

```
